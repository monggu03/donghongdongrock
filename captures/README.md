# 캡처 넣는 곳

이 폴더에 아래 이름으로 이미지를 넣고 PR을 올리면, 빌드할 때 슬라이드의 캡처 자리가 그 이미지로 바뀝니다.
라이트 모드, 브라우저 확대 110~125%로 찍고 이메일·프로젝트 번호·프로젝트 ID는 가립니다.

| `pr-green.png` | 다시 초록 | 같은 PR: All checks have passed · 초록 Merge 버튼 |
