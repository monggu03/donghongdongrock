손으로 하는 배포: 서버에 접속해 명령을 한 줄씩

$ ssh deploy@my-server
$ cd app && git pull
$ npm install
$ npm run build
$ sudo systemctl restart app
$ curl -I https://my-app.example
HTTP/1.1 502 Bad Gateway

명령을 다 쳤으면, 이제 아무 일 없기를 기도

운영 서버

my-app.example

정상 운영 중 앱 응답 없음 · 502

사용자 접속 불가

그 주에 하는 배포는 보통 이렇게 생겼습니다. 지금도 많은 학생 프로젝트가 이렇게 합니다. 서버에 접속해서, 코드를 받고, 설치하고, 빌드하고, 재시작합니다. (클릭) 그리고 아무 일 없기를 기도합니다. (클릭) 그런데 주소를 열어 보면 502. 앞단 서버는 살아 있는데 그 뒤의 앱이 응답하지 않습니다. 사용자는 아무것도 못 씁니다.
