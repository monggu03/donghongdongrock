이 길 전체가 레포 안 파일 한 개

on:
  pull_request:
  push:
    branches: [main]
jobs:
  check:
    name: frontend-check
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - run: npm ci
      - run: npm run lint
      - run: npm test
      - run: npm run build
  deploy:
    needs: check
    if: github.event_name == 'push'

1트리거

PR 열기 → pull_requestmain에 머지 → push

2러너

ubuntu-latest, 빌려 쓰는 리눅스

3단계

코드 받기, 그다음 검사 네 개를 차례로

4배포

needs: 검사가 통과해야 출발
if: main에 머지됐을 때만 배포

방금 본 길 전체가 레포 안 파일 한 개에 적혀 있습니다. 첫 번째, 트리거. 언제 출발할지입니다. PR을 열면 pull_request, main에 머지하면 push입니다. (클릭) 두 번째, 러너. 어디서 돌지입니다. ubuntu-latest, 빌려 쓰는 리눅스입니다. (클릭) 세 번째, 단계. 맨 위 checkout은 빈 러너에 코드를 받아 오는 줄이고, 그 아래가 아까 본 검사 네 개입니다. (클릭) 네 번째, 배포. needs는 검사가 통과해야 출발한다는 뜻이고, if 줄 덕분에 PR에서는 검사만 하고 main에 머지됐을 때만 배포합니다.
