다시 빌드하지 않아서 몇 초

Cloud Run: 배포마다 남는 이전 버전(리비전)으로 트래픽 100% 이동

Merged#13Revert버튼 한 번으로 main 코드도 되돌리는 PR
되돌리는 방법은 간단합니다. 아까 보관소에 v1을 남겨 뒀습니다. (클릭) 그 v1 이미지를 다시 운영에 올립니다. 다시 빌드하지 않으니까 몇 초면 됩니다. 실습 백엔드를 올린 Cloud Run은 배포마다 버전을 리비전으로 남겨서, 트래픽 100%를 이전 리비전으로 옮기면 끝입니다. (클릭) 다만 main에는 아직 v2 코드가 남아 있어서, GitHub의 Revert 버튼으로 되돌리는 PR도 올립니다. 이것도 CI와 CD를 똑같이 한 바퀴 돕니다.
