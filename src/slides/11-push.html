CI: PR을 열면 검사가 자동으로 출발

$ git push origin feat/timetable

그다음 GitHub에서 PR 열기

PR 열기 → on: pull_request
이제 CI가 있으면 어떻게 되는지 보겠습니다. 여기서부터 화면은 이 발표용으로 만든 시간표 예제 앱, 실습 레포에서 실제로 돌린 결과입니다. 시간표 기능을 고친 커밋을 올리고 PR을 엽니다. 카트에 붙은 글자가 커밋 번호입니다. (클릭) 그 순간 GitHub가 PR이 열린 걸 알고 검사를 자동으로 출발시킵니다. 아무도 버튼을 누르지 않았습니다. 달라진 건 PR마다 검사가 붙었다는 것 하나입니다.
